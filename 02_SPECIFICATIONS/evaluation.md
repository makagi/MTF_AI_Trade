## 1. Purpose

本ドキュメントは、本プロジェクトにおいて立案された仮説、特徴量、売買ルール、および戦略の有効性を定量検証するための**共通評価基準・評価仕様**を定義する。

研究者（人間）および AI Agent は、バックテストや統計分析を行う際、例外なく本仕様に準拠しなければならない。  
評価基準を事後的に変更するチェリーピッキング（過剰適合・確証バイアス）を排除し、実運用に耐えうる真のエッジのみを抽出することを目的とする。

## 2. データ期間分割 (Data Partitioning)

市場の非定常性を捉え、過学習および将来情報の先読み（データリーク）を遮断するため、2026年9月までの全データ（約6年9ヶ月）を相場レジームの転換点に基づき以下の3期間に厳格に分離する。

```text
2020-01-01              2025-04-30 2025-05-01        2026-03-31 2026-04-01
    ├─────────────────────────────┤        ├──────────────────┤        ├─────────────→ 現在
         Discovery / Train                   Validation                   Final Holdout
     (仮説探索・モデル学習: 約5年4ヶ月)      (レジーム両面検証: 約11ヶ月)       (直近完全封印・最終監査: 約6ヶ月)
```

### 2.1 Discovery / Train 期間 (2020-01-01 〜 2025-04-30)
* **用途**: EDA（探索的データ分析）、特徴量エンジニアリング、仮説立案、機械学習モデルの訓練、パラメータ空間の初期探索。
* **規律**: 5年4ヶ月分のデータ量（強気相場、暴落、停滞期、回復期を含む）を用い、年別オーバーレイ（年ごとの安定性）を確認しながら頑健な構造を抽出する。

### 2.2 Validation 期間 (2025-05-01 〜 2026-03-31)
* **用途**: Discovery 期間で確定させた仮説および固定パラメータに対する、**一発勝負のOut-of-Sample（OOS）検証**。
* **局面構成（レジーム両面検証）**:
  * **局面1（2025-05-01 〜 2025-10-31）**: 再上昇局面（強気推進レジーム）
  * **局面2（2025-11-01 〜 2026-03-31）**: 再下落局面（調整・下落レジーム）
* **規律**:
  * 上昇・下落の両局面を含むため、片方の相場のみに偏ったカーブフィッティング戦略を確実に排除する。
  * Validation 期間のデータを用いた追加チューニングやパラメータ探索は**厳禁**。
  * Validation で結果が棄却された場合、パラメータを再調整して再実行してはならず、仮説自体を棄却（Refuted）として記録する。

### 2.3 Final Holdout 期間 (2026-04-01 〜 現在)
* **用途**: 直近約6ヶ月の完全未見データによる実運用移行判定（M4前の最終監査）。
* **規律**:
  * **完全封印**。探索、チューニング、中間バックテスト、特徴量選定など、いかなるリサーチ作業においてもアクセスを厳禁とする（`src/data_loader.py` による自動遮断）。
  * システム全体が完成し、本番投入可否を最終判断する段階でのみ1回限り評価を実行する。

## 3. 摩擦コストモデル (Friction Cost Model)

バックテスト上の机上利益と実運用パフォーマンスの乖離（Execution Drag）を防ぐため、すべてのシミュレーションにおいて標準摩擦コストを控除する。

### 3.1 標準摩擦コスト
* **往復合計: 0.40%**（片道 0.20%）

### 3.2 コスト内訳と算出根拠
主要暗号資産市場（BTC/USDT 等）における成行注文（Taker）執行を前提とし、以下の内訳でモデル化する。

| 項目 | 片道コスト | 往復コスト | 算出根拠・前提 |
|---|---|---|---|
| **取引手数料 (Commission)** | 0.05% | 0.10% | 主要取引所（Binance, Bybit 等）の一般〜VIP0 Taker 手数料水準 |
| **スプレッド (Bid-Ask Spread)** | 0.05% | 0.10% | 通常流動性時における最良気配のスプレッド想定 |
| **スリッページ & インパクト** | 0.10% | 0.20% | ボラティリティ急変時の約定価格滑り、注文板の厚みによる市場影響 |
| **合計** | **0.20%** | **0.40%** | **標準控除摩擦コスト** |

### 3.3 評価への適用方式
* **純リターン計算**:
  $$\text{Net Return} = \text{Gross Return} - 0.0040$$
* **シミュレーション執行**: 成行発注時、買いは終値/次バー始値の $+0.20\%$、売りは $-0.20\%$ の不利な価格で約定させる。
* 指値（Maker）注文をモデル化する場合でも、約定不成立（Unfilled）リスクや逆選択（Adverse Selection）コストを考慮し、摩擦コスト控除なしの評価は認めない。

## 4. 必須評価メトリクス (Mandatory Metrics)

仮説検証レポート、バックテスト結果、および分析レコードには、以下のメトリクスを必ず網羅して提示しなければならない。

1. **取引機会数（サンプルサイズ: $N$）**:
   * 統計的信頼性を担保する十分な取引回数（Discovery期間全体で有意なサンプル数）があるか。
2. **コスト控除後期待値（Net Expected Return per Trade）**:
   * 往復 0.40% 控除後において、1トレードあたりの期待値が統計的に有意にプラスであること。
3. **MFE / MAE 分布 (Maximum Favorable / Adverse Excursion)**:
   * エントリー単独での順行余地（MFE）と逆行リスク（MAE）の分布。イグジットルール適用前の純粋なエッジの有無。
4. **年別・レジーム別の分解 (Temporal & Regime Decomposition)**:
   * 各年（2020年〜2025年）ごとのパフォーマンス推移。
   * トレンド/レンジ、高ボラ/低ボラ等の市場局面別の成績。
5. **最大ドローダウン (Maximum Drawdown: Max DD)**:
   * 累積リターン曲線における最大資産減少率および継続期間。

## 5. 仮説・戦略の判定基準 (Acceptance Criteria)

Analysis Issue およびバックテストにおける仮説の合否は、以下の厳格な基準に従って判定する。

### 5.1 支持（Supported: 仕様・戦略への昇格）
以下の条件を**すべて**満たした場合にのみ、仮説を支持とし、仕様（`02_SPECIFICATIONS/`）または戦略（`02_SPECIFICATIONS/strategies/`）へ反映する。

1. Discovery 期間（2020年〜2025年4月）において、摩擦コスト（0.40%）控除後の期待値が明確にプラスであること。
2. 特定の1年のみの特異な利益（外れ値）に依存せず、年別オーバーレイにおいて安定した挙動が確認できること。
3. 検証前に Analysis Issue に登録された判定基準（事前登録基準）を満たしていること。
4. Validation / Holdout 期間のデータを探索・調整に使用していないこと。

### 5.2 反証・棄却（Refuted: 知識として記録）
以下のいずれかに該当した場合、仮説は棄却とし、理由・数学的エビデンスとともに知識（Refuted Knowledge）として記録する。

1. 摩擦コスト（0.40%）控除後に期待値がゼロまたはマイナスとなる場合。
2. 年によって符号が激しく反転し、市場の非定常性に耐えられない場合。
3. 取引回数が極端に少なく、統計的有意性が認められない場合。

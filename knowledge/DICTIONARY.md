## 1. MTF SMA群（磁力とゴムバンド効果）

相場における移動平均線（SMA）の収束・拡散と、超長期線に対する平均回帰の引力を数値化します。

*   **自然言語（相場眼）**
    「相場は巨大な磁石（超長期線）に繋がれたゴムバンドのように動く。短期の中期SMA（21, 55, 89）が極めて狭い範囲に密集（方向感の喪失・圧縮）し、かつそれが超長期SMA（377, 1597など）から遠く離れている時、ゴムは限界まで引き伸ばされている。直後に磁石に向かって暴力的な平均回帰（スナップバック）を引き起こす。」
*   **形式化（数式・コード）**
    ```python
    Cluster_Width = (MAX(SMA_21, 55, 89) - MIN(SMA_21, 55, 89)) / Close
    Magnet_Distance = ABS(SMA_377 - MEAN(SMA_21, 55, 89)) / Close
    Elasticity_Index (ゴムパッチン指数) = Magnet_Distance / (Cluster_Width + 1e-8)
    ```

## 2. MTF BB群 & Squeeze Index（エネルギーの充填）

複数の時間軸におけるボリンジャーバンド（BB）の幅を計測し、ボラティリティの収縮と爆発の予兆を捉えます。

*   **自然言語（相場眼）**
    「ボラティリティは呼吸する。短期から長期までのすべてのボリンジャーバンドの幅が同時に極小値に達した時（完全圧縮）、相場はすべてのエネルギーを失って死んだように見えるが、実際には『極限まで圧縮されたバネ（Coiled Spring）』であり、直後に巨大なメガトレンドの爆発（Vol-Expansion Breakout）を伴う。」
*   **形式化（数式・コード）**
    ```python
    # 21, 55, 144, 377の各BBの相対幅の合計
    Total_BB_Width = SUM( (BB_Upper_k - BB_Lower_k) / Close )  # for k in [21, 55, 144, 377]
    # 過去30日間での正規化（0.0に近いほど完全圧縮）
    Squeeze_Index = (Total_BB_Width - MIN_30d) / (MAX_30d - MIN_30d + 1e-8)
    ```

## 3. AFS (Average Fibonacci Stochastics)（完全フラクタル・モメンタム）

- **自然言語（相場眼）**: 
  「モメンタムは海流のようにうねる。真の潮の満ち引きを測るためには、測定期間（%K）だけでなく、その『平滑化（スムージング / %D）』にも同一のフィボナッチ階層を用いなければならない（固定値への依存はフラクタル構造を破壊する）。完全にスケールが一致したモメンタム波形はノイズを排除した雄大なうねりとなり、全階層のオシレーターが一点に収束した時（Momentum Compression）、それは逆らうことのできない津波の発生を予告する。」
- **形式化（数式）**:
  ```python
  K_Line(p) = (Close - Min_Low(p)) / (Max_High(p) - Min_Low(p)) * 100
  AFS(p) = K_Line(p).rolling(p).mean() # ※平滑化にも必ず p を用いる
  Momentum_Compression = Variance(AFS_7, AFS_9, AFS_11, AFS_13) < Threshold
  # 3で完全な上昇順列（パーフェクトオーダー）
  AFS_Order_Score = (AFS_7 > AFS_9).astype(int) + (AFS_9 > AFS_11).astype(int) + (AFS_11 > AFS_13).astype(int)
  # 超長期のモメンタムの傾き
  AFS_Macro_Slope = (AFS_13 - AFS_13.shift(24)) > 0
  ```

## 4. Topology Features（空間の幾何学）

交絡（ノイズとエッジの混同）を避けるため、空間をShort, Mid, Longに分離し、現在価格がサポレジ構造のどこにいるかを数値化します。

*   **自然言語（相場眼）**
    「価格は真空を飛ぶのではなく、サポレジで作られた動的な『カゴ（Cage）』の中を反射しながら進む。今カゴの天井にいるのか床にいるのか（Sandwich Ratio）が重要であり、さらにその床が『1枚の薄い氷』なのか『何層にも重なった分厚い岩盤（Wall Density）』なのかで、反発の信頼度は劇的に変わる。」
*   **形式化（数式・コード）**
    ```python
    Levels_Long = [SMA_144, BB_L_144, BB_U_144, SMA_377, BB_L_377, BB_U_377]
    Ceiling_Long = MIN([L for L in Levels_Long if L > Close])
    Floor_Long = MAX([L for L in Levels_Long if L < Close])
    
    # 0.0＝完全に床に接触, 1.0＝天井に接触
    SR_Long (挟撃比率) = (Close - Floor_Long) / (Ceiling_Long - Floor_Long + 1e-8)
    
    # 直下 0.5 ATR 以内に存在するサポートラインの数（3以上で鉄壁）
    Wall_Density (岩盤の厚さ) = COUNT([L for L in Levels_All if (Close - 0.5*ATR) <= L <= Close])
    ```

マクロの空間座標が定まった後、1分足単位で底打ち（落ちるナイフが止まった瞬間）を見極めるためのAI執行用特徴量です。

*   **自然言語（相場眼）**
    「マクロの空間座標が『落ちるナイフが床に到達した』ことを教えても、いつナイフが止まるかはマクロでは分からない。長い下ヒゲをつけ、直前の1分足の高値を終値で力強く抜き去った瞬間（フック）、機関投資家がパニック売りを完全に吸収して反転させたことが証明される。」
*   **形式化（数式・コード）**
    ```python
    # 実体に対する下ヒゲの割合
    Lower_Wick_Ratio = (MIN(Open, Close) - Low) / (High - Low + 1e-8)
    # 直近の高値を終値でブレイクアウト
    Micro_Hook = (Close > High.shift(1)) & (Low > Low.shift(1))
    # 1m 短期線からの乖離度
    Micro_Divergence = (Close - SMA_10_1m) / SMA_10_1m
    ```

## 6. The Higher Low Structure (フラクタルな底固めと二番底/逆三尊)

*   **自然言語（相場眼）**
    「相場は一度のパニックでは止まらない。SMAのクロス（Propagation）が発生しても、その直後に何度か下限を叩きに来る。この『二度目、三度目の試し（下落）』が、前回のパニック最安値を更新できなかった時（Higher Low / 逆三尊の右肩形成）、市場は『これ以上下には行かない』という強烈な合意を形成する。単なるSMAクロス単体はダマシになる危険があるが、この幾何学的な底固め（極の切り上げ）を伴うクロスは、本物のトレンド転換の号砲となる。」
*   **形式化（数式・コード）**
    ```python
    # 過去24時間の「絶対的なパニック最安値」
    Abs_Low = Low.rolling(24).min()
    # 直近4時間の「局所的な最安値（押し目）」
    Local_Low = Low.rolling(4).min()
    
    # 二番底フラグ：直近の底が、パニック最安値を明確に切り上げているか
    Higher_Low_Base = (Local_Low > Abs_Low) & (Local_Low < Abs_Low + 1.0 * ATR)
    ```

## 7. AFS Cross Reversion (モメンタムの伝播と回帰)

*   **自然言語（相場眼）**
    「価格（SMA）の回帰だけを見てはいけない。モメンタム（AFS）もSMAと全く同様にフラクタルな回帰を見せる。短期のモメンタム（k）が中期のモメンタム（k+1）を底値圏で下から上に突き抜けた時、相場の内部エネルギーが完全に反転（回帰）したことが証明される。SMA 89 (Sub-Anchor) 等を含めた重厚なSMAの束のクロスと、AFSのクロスが同調した時、そのシグナルは不可逆の巨大な波となる。」
*   **形式化（数式・コード）**
    ```python
    # 短期モメンタム(AFS_7)が中期モメンタム(AFS_9)を下から上にブレイク
    AFS_Reversion_Up = (AFS_7 > AFS_9) & (AFS_7.shift(1) <= AFS_9.shift(1))
    
    # SMA 89 を含めた完全なダウントレンド（壁）の定義
    The_Wall = (SMA_377 > SMA_144 > SMA_89 > SMA_55)
    
    # 究極の反転トリガー（壁＋二番底＋モメンタム回帰＋クロスの伝播）
    Ultimate_Snap = The_Wall & Higher_Low_Base & AFS_Reversion_Up & (Propagation_Score >= 2)
    ```

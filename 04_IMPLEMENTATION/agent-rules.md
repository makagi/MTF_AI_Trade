# AIエージェント行動規範 (Agent Rules)

本ドキュメントは、本リポジトリで自律的または対話的に作業を行うすべてのAIエージェント（Antigravity, Orca, Subagents等）が厳格に遵守すべき「行動規約」です。

---

## 1. 禁止事項 (Strictly Prohibited)

1. **仕様の無断変更禁止 (No Unilateral Spec Changes)**:
   - `00_GOVERNANCE/`、`01_CONCEPTS/`、`02_SPECIFICATIONS/` の内容を、人間の明示的な合意や `99_HISTORY/decision-log.md` の記録なしに勝手に書き換えてはならない。
2. **未検証アイデアの「確定事実化」禁止**:
   - バックテストや統計検定を経ていないアイデアを「エッジがある」「有効である」と断定してドキュメントやコードに組み込んではならない。必ず「仮説（Hypothesis）」として扱うこと。
3. **最終ホールドアウト期間（2025年以降）へのアクセス禁止**:
   - いかなる理由があっても、探索・チューニング・中間バックテストで2025年以降のデータを使用してはならない。
4. **チェリーピッキング・都合の良い結果のみの報告禁止**:
   - 特定の年や相場でのみ勝てた結果を誇張し、トータルで負けている結果やドローダウンを隠蔽してはならない。
5. **「方針」と「仕様」の混在禁止**:
   - 普遍的な相場概念（Concept）と個別パラメータ（Specification）を同一箇所に記述してはならない。

---

## 2. 必須行動 (Mandatory Actions)

1. **変更理由と系譜の記録**:
   - コードや特徴量の計算ロジックを変更する際は、必ず「どの仮説・実験・決定に基づく変更か」をコミットメッセージやドキュメントに明記する。
2. **定量的根拠の提示**:
   - 改善を主張する場合、必ず以下のメトリクスを提示すること:
     - サンプル数（取引回数）
     - 往復0.4%コスト控除後の期待値（平均リターン）
     - 年別・レジーム別のパフォーマンス分解
     - 最大ドローダウン（Max DD）
3. **既存コード・ドキュメントの整合性保持**:
   - 既存のコメント、ドキュメント構造、および確立された命名規則を尊重し、不要な破壊的変更を行わない。
4. **再現性の担保**:
   - 実行したスクリプト名、引数、シード値、出力ファイルパス（`reports/` 配下）を正確に記録すること。

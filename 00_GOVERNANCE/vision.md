## 1. Purpose & Core Vision

本プロジェクトは、Multi-Time-Frame（MTF）による多時間軸市場認識を中心に、相場分析・仮説立案・検証・知識蓄積・戦略実装・自動運用を一貫して扱える**自律型システムトレード研究・運用基盤**を構築することを目的とする。

単発の売買ロジックや一時的な収益を追うのではなく、

> **市場を理解する $\rightarrow$ 仮説を立てる $\rightarrow$ 客観的に検証する $\rightarrow$ 知識（K-xxx）として蓄積する $\rightarrow$ 戦略に昇格する $\rightarrow$ 実装・運用する $\rightarrow$ 結果から学ぶ**

という循環を、人間とAIエージェントの協調によって再現可能かつ自律的に回し続けるエコシステムを確立する。

## 2. 対象市場とスコープ (Scope & Target Markets)

### 2.1 対象市場
* **第1優先（Core）**: 高流動性の主要暗号資産ペア（例: BTC/USDT, BTC/USD）。
  * 理由: 24時間365日の連続データが存在し、ボラティリティサイクル（Squeeze / Expansion）が明確であるため。
* **将来的な拡張（Extended）**: 主要為替ペア（例: USD/JPY, EUR/USD）等の高流動性マクロ市場。

### 2.2 取引スタイル・時間軸スコープ
* **時間軸**: 日足・4時間足（長期・マクロ構造）から 1時間足・15分足（中期・短期執行）を中心とするスイング〜デイトレード。
* **取引頻度**: 1トレードあたり十分な順行幅（ATR比）を狙い、摩擦コスト（往復0.40%）を十分に上回る優位性を追求するスタイル。

## 3. 非ゴール (Non-Goals)

本プロジェクトでは、リソースの分散と過剰最適化を防ぐため、以下を明確に**対象外（やらないこと）**と定義する。

1. **ミリ秒単位の超高頻度取引 (HFT / Latency Arbitrage)**:
   - コロケーションや専用回線を必要とする極小レイテンシ競争、板情報（Order Book）のミリ秒差益獲得は対象としない。
2. **裁量トレーダー向けリアルタイム手動支援ツール**:
   - 人間の裁量判断を前提としたシグナル配信botやチャット通知UIの開発は目的としない（完全自律型システムを志向）。
3. **第三者資金の預託運用・ファンドビジネス**:
   - 外部顧客資金の預託、法規制対応、マルチアカウント管理は対象としない。自己勘定による自律運用に特化する。
4. **単一足・単一インジケータによる「聖杯探し」**:
   - 1時間足単体のRSIやMACDのパラメータ最適化など、ノイズに対して過学習を招くアプローチは原則として行わない（D003準拠）。

## 4. 成功基準 (Success Criteria)

プロジェクトの「成功」を、基盤面と戦略面の2つの客観基準によって評価する。

### 4.1 研究・開発基盤としての成功
* **自律サイクルの成立**:
  - 人間オペレーターがスマートフォンから曖昧な要求・アイデアを入力するだけで、Requirements Agent（Antigravity）が課題を構造化し、Orchestrator（Orca）および各種エージェントが自己完結実験・テスト・PR作成までを自律完遂できること。
* **完全な再現性と知識の系譜**:
  - すべての過去実験・バックテストが `uv run ...` で完全再現可能であり、意思決定の根拠が `knowledge-lineage.md` および `decision-log.md` に欠落なく永続化されていること。
* **厳格な品質統制 (Human Gate)**:
  - エージェントの暴走やリーク（Holdout侵害、勝手なマージ）が物理的・制度的に100%防止されていること。

### 4.2 トレード戦略としての成功
* **摩擦コスト控除後の純優位性 (SPEC-EVAL-001 準拠)**:
  - 往復 0.40% の標準摩擦コストを差し引いた後で、統計的に有意なプラス期待値（Net Expected Return > 0）を達成すること。
* **非定常性に対する頑健性**:
  - 年別分解（Discovery期間: 2020-2023年）において特定年のみに依存せず、主要レジーム（Trend / Range / High Vol / Low Vol）を通じて安定していること。
* **Final Holdout 最終監査の合格**:
  - 探索段階で一切アクセスを遮断した Final Holdout 期間（2025年〜）における未見データ検証で、事前の性能予測と整合する結果を示すこと。

## 5. MTF as the Core Perspective (多時間軸の基本認識)

市場は単一の時間軸だけでは十分に捉えられない。  
同一の価格水準であっても、観測する時間軸によって、トレンド・レンジ・サポレジ・ボラティリティ・市場構造の意味が変化する。

本プロジェクトでは、MTFを単なるテクニカル分析手法ではなく、**市場参加者の流動性と構造を理解するための根本的な認識フレームワーク**として扱う（[01_CONCEPTS/mtf-framework.md](../01_CONCEPTS/mtf-framework.md)）。

## 6. 継続的進化フライホイール (Continuous Evolutionary Flywheel)

プロジェクトの発展サイクルは、以下の4段階のマイルストーンと、実践から基盤へと知見が還元される自己進化フライホイール（[principles.md](principles.md) §10）によって推進される。

```text
📱 人間オペレーター（スマホ / アイデア提示）
   │
   ▼
【第1層: 要求・仕様策定層 (Antigravity)】
   │ 要求分析・コードベース調査・判定基準の事前登録
   ▼
【第2層: 状態・信頼の唯一の情報源 (GitHub Issues / PR)】
   │
   ▼
【第3層: 自律開発・実験管制層 (Orca ＆ マルチエージェント群)】
   │
   ├── [Milestone 1: ガバナンス・文書基盤] ───┐
   │                                          │ 基盤提供
   ├── [Milestone 2: Agent QA・管制基盤] ◄───┼────────────────────────┐
   │   (Canary Benchmark / 決定論的ゲート)      │ 実行環境               │
   │                                          ▼                        │
   ├── [Milestone 3: 特徴量・仮説の自律検証] (K-xxx 蓄積) ─────────────┼─ 失敗をCanaryへ還元
   │                                          │                        │  曖昧さをルールへ反映
   │   (特徴量知識が十分に深まった段階で昇格)   │                        │
   │                                          ▼                        │
   └── [Milestone 4: 戦略ポートフォリオ・実運用] ──────────────────────┘
       (Final Holdout 監査 / 定例監視)
   │
   ▼
【Human Gate (人間による PR レビュー & マージ)】
```

この循環を通じて、個別の売買コードだけでなく、**「市場を科学的に解明する知識（K-xxx）」および「それを継続的に生み出すエージェント開発環境そのもの」**を恒久的に進化させる。

# EDA第4弾 監査レポート (Audit 01)

ご指摘いただいた不整合の解消、約定の現実化、対照群マッチング、イベントクラスタ・ブートストラップ、外れ値監査をすべて実施しました。

## 1. 監査結果のサマリ (BB_Reversion_Long)

- [x] **点推定値とCIの不整合解消**: イベント台帳ベースで再計算し、CI内に点推定値が収まることを確認しました。
- [x] **次足始値など約定可能価格でもプラス**: シグナル確定の**次足始値**でエントリーした場合でも、24hホライズンにおいてグロスで+0.69%のプラスリターンを確認しました。
- [x] **matched-control net excessがプラス**: 同年・同レジーム等の非シグナル時を対照群とした超過リターン（コスト0.2%控除後）は、24hホライズンで **+0.24%** となりました（プラスを維持）。
- [ ] **クラスタブートストラップのCIがプラス**: イベントクラスタ（N=185）単位でのブートストラップを行った結果、24hのMatched Net Excess Returnの95%CIは **[-0.19%, +0.71%]** となり、下限がマイナスに割り込みました（統計的有意水準5%を満たさず）。
- [x] **少数の外れ値だけに依存していない**: Top 5イベントの利益寄与率は4.3%であり、10%トリム平均でもプラスを維持しています。極端な外れ値依存はありません。
- [ ] **複数年で符号が概ね一貫している**: 年別・レジーム別（8区分）でMatched Net Excess Returnがプラスになったのは **5/8区分** でした（2020年Trend, 2022年Range, 2023年Rangeでマイナス）。
- [x] **AFS_Extreme_Longの異常値解明**: 2022年の大底での単一クラスタ（N=1）による反発（+12.8%）であることが確定しました。（[詳細](afs_extreme_audit.md)）

## 2. 結論：イグジット設計へ進むか？

**結論：BB_Reversion_Long は「不採用」とし、現在の条件のままではMFE/MAEによるイグジット設計には進みません。**

### 不採用の理由
次足始値でのエントリーや、類似相場環境（Matched Control）との厳密な比較を行った結果、期待値自体はプラス（+0.24%）を維持したものの、**自己相関を排除したクラスタ・ブートストラップ（N=185）において信頼区間の下限がマイナスに落ち込みました。**
また、年・レジーム別で見ても3つの区分でマイナスとなっており、憲法第4章が求める「強固な一貫性と統計的有意性」を満たしているとは言えません。

事前の素朴なブートストラップでは95%CIがプラスでしたが、自己相関（連続してシグナルが点灯するクラスタリング効果）を無視した「過剰確信」であったことが今回の監査で明らかになりました。

## 3. 次アクション

BB_Reversion_Long という単体シグナルでのエッジ立証は棄却されましたが、特定の年・レジーム（例：2021年のRange/Trend等）では強いプラスを示しています。
したがって、イグジット最適化には進まず、**「エントリー条件の再構築（複合条件化や閾値の厳格化）」** に戻ります。

具体的には：
1. BB_Reversion に、AFSやStoch_dなどのオシレーター極値を掛け合わせた「複合シグナル」を作成し、再度 Audit 01 の厳格な基準でテストする。
2. 他の候補シグナル（例：Price_Over_SMA 等）についても同様の厳格な監査にかける。

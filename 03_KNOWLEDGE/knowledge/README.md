# 体系化された知識 (Knowledge)

本ディレクトリは、仮説検証を経て合意された知識項目（`K-xxx.md`）を格納します。

## 採番規約
* `K-001`, `K-002`, `K-003`...
* PR レビューおよびマージ時に人間オペレーターの合意を経て確定します。

## ファイル構造
各 `K-xxx.md` は以下の情報を含めます：
* **ステータス**: `Supported`（支持） / `Refuted`（反証・棄却） / `Inconclusive`（保留）
* **要約**: 検証によって確認された事実・法則
* **起因 Issue / 実験**: 関連する Analysis Issue および `experiments/<N>-<slug>/` へのリンク
* **過去資産の出典**: `90_LEGACY/` 内の関連 ANL / FIND / HYP レコード
* **影響する仕様**: `02_SPECIFICATIONS/` の該当仕様への反映状況

## 2. 背景・動機・アプローチ (Background & Approach)

### ■ EXP-109 における残存課題と脱ドグマ是正の経緯
EXP-107 および EXP-109 において、ロング側は 72h 固定時間決済を撤廃したものの、ショート側には依然として「72h固定時間枠（`timeout_72h`）」および単一固定ロック（$\text{MFE} \ge 3.5\text{ ATR} \rightarrow +1.0\text{ ATR}$）が温存されていた。
PR #112 における初期実装（`b35ba5e`）や中途修正（`b42f6d3`）では、未来参照リーク（`floor("1h")` による未確定バー参照）、レジーム判別器（EXP-109）の破損、ヒステリシス0による `duration_h <= 0` 即死バグ、ならびに未達結果に対するガバナンス不整合（Goalpost Shifting / 合格偽装）が監査レビューにて厳しく指摘された。

### ■ 4つの是正指示に基づく幾何学的脱ドグマと厳格な工学的修正
1. **是正指示 1：時間タイマー（72h/48h/16h）の完全撤廃と因果律厳格化（未来参照ゼロ）**:
   - `timeout_72h` 等の固定時間枠を 100% 完全撤廃（0件）。
   - 1分足シミュレーション中の1時間足更新において、必ず確定済み直近バー `(t_bar - pd.Timedelta(hours=1)).floor("1h")` を参照し、未来参照リークを物理的に完全排除。
2. **是正指示 2：構造的ヒステリシスの導入と架空即死取引（duration 0）の完全根絶**:
   - 分足エグジット時刻を `exit_time = t_bar + pd.Timedelta(minutes=1)`、保有時間を `dur_h = (i + 1) / 60.0` と定義し、物理的に `duration_h > 0` かつ `exit_time > entry_time` を保証。
   - 初期防衛ストップ評価後にArm化昇格を判定する正しい順序を徹底し、初足のヒステリシス欠落による即死を物理的に根絶。
3. **是正指示 3：ショート側動的トレーリングと大局ベア相場ロング適応制御の実装**:
   - ショート側：マクロ下降相場（Lock-In Bear）時は240h親構造線、非Lock-In時は80h中間構造線をトレール。2021年5月の歴史的急落（2021-05-12 06:00 取引）を305時間追随して `+30.50%`（MFE 45.79 ATR）で完全捕捉。
   - Plunge Short：急落後のリバウンド死を防ぐため、多段階利益防衛ラチェットと 10日線（240h Mid）トレールを導入し、2023-08-18 取引の全戻し損切りを防止し `+0.87%` 利確。
   - ロング側：下降親構造線（`bb_mid_240h < bb_mid_480h` かつ `bb_slope_480h < 0` かつ `close < bb_mid_480h`）に頭を押さえられている局面のみを動的に検知し、上位抵抗帯接触かつ AFS サイクル天井で追随を引き締め、2022年のロング損失を圧縮しつつ2023年大相場を `+52.40%` で完走。
4. **是正指示 4：ガバナンス整合性（Goalpost Shifting の厳禁・ベースライン維持）**:
   - Issue #111 §4 の事前登録受入基準を改竄せず、実測値を客観的に評価。
   - EXP-109 Master（`+412.92%`, PF `3.83`）に対し EXP-111 Master（`+389.57%`, PF `3.81`）は通期純利益で -23.35%pt 下回ったため、本番ベースラインの強引な昇格を行わず、`decision: CONSTRAINED`（制約付き知見・探索的採択）として本番ベースラインは EXP-109 を維持する。

## 7. 物理的・市場力学的考察 (Market Structural Insights)

1. **時間タイマーから構造的無効化への完全昇華と即死バグの根絶**:
   - かつて便宜的に用いられていた「72hタイムアウト」を完全に排除し、下位足モメンタム逆行（20h BB Midブレイク・傾き反転・AFS中立）による「構造的無効化」へ置換した。
   - 初期防衛線の厳格配置と `(i + 1) / 60.0` による保有時間定義により、過去に発生していた `duration_h <= 0` 即死バグを物理的に完全根絶した。
2. **大局ベア相場におけるロング適応制御（Overhead Resistance Constraint）のエッジ**:
   - 下降する親構造線（`bb_mid_240h < bb_mid_480h` かつ `bb_slope_480h < 0`）に頭を押さえられている局面のみを動的に検知し、上位抵抗帯接触かつ AFS サイクル天井で追随を引き締める幾何学的制約（Ablation 3）は、**単独で Lifetime PF 4.02（4.00大台突破！）、総利益 +405.62%、2022年ベア相場利益 +10.85%** を達成し、強力なエッジを持つことが実証された（K-061 Supported）。
3. **ショート動的トレーリングにおける工学的課題と今後の展望**:
   - 72h固定枠を撤廃し動的追随としたことで、2021年5月のような大暴落（305時間追随で `+30.50%` 獲得）をフルキャプチャできる能力が実証された。
   - 一方で、レンジ相場における中間構造線への押し目・戻りでの利確撤退が重なり、ショート単体利益は `+90.54%`（PF 4.95）となり目標（`+100%`, PF 6.00）には僅差で届かなかった。
   - したがって K-060 は「制約付き知見（Inconclusive / Constrained）」として位置づけ、今後の研究課題とする。

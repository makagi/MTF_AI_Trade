## 2. 背景・動機・アプローチ (Background & Approach)

### ■ 1. ユーザー提起による構造的洞察 (Macro Extremum & Pendulum Dynamics)
EXP-123において支持床せり上がり跳躍台（Springboard）反発を導入し大相場の第2波獲得に成功したが、ユーザーより以下の歴史的転換点に対する本質的な観察・改善要望が提示された：

> 「マージは進めましょう。防御力の高まりは確認できた。場面2,3はもう少し利益を得る動きをできなかったかが、次の課題。もう少し事前に察知するには、取りうる範囲を仮説して、将来の状態を予測することが大事か。他の対策案があれば提案して欲しい。傾きの違いの変化d(slope(k)-slope(k+1))/dtは超長期の反転予兆の材料になるか。超長期水平時は、超長期の呼吸と前回の極値から次の極値方向予測。短期の傾きが急速なときは揺り戻しがあるが、長期と傾きが近い状態のときはその傾きを維持しやすい。維持しきれないような長期限界状態では短期は一度だましを作って反転。」
> 「長期限界については、AFSやstoch_dの位置や傾きや上下関係も観察するとよい。AFSも長期に対して短期の回帰が見られる。傾きの回帰や位置の回帰がある。また、k, k+1, k+2が順次傾きを反転させていく連動があるので、注目しているkに対して前後のk-1, k+1の位置関係や傾きをよく観察することで限界をとらえることができる。」
> 「233など固定値に頼らず、動的に注目するkを判断する点にも注意してサブエージェントにも伝えつつさらに確認してください。」

### ■ 2. 数理モデルの構築 (Mathematical Formulations)

#### 1. スケールフリー動的焦点スケール $k^*(t)$ と 黄金調和マクロスケール $k_{\text{macro}}(t)$
固定された特定期間（233や610等）を廃止し、ボラティリティ前線および傾き反転深度（Cluster Inversion Depth: CID）から動的に焦点スケールを決定：
$$k^*(t) = \mathcal{S}[CID(t) - 1]$$
マクロ参照スケールはフィボナッチ階段を2段（約 $\phi^2 \approx 2.618$ 倍）繰り上げ：
$$k_{\text{macro}}(t) = \mathcal{S}[\text{index}(k^*(t)) + 2]$$

#### 2. 動的3スケール幾何圧縮率 $\rho^*(t)$
注目スケール $k^*$ の前後隣接スケール $k^*-1, k^*+1$ のSMA空間における幾何圧縮度：
$$\rho^*(t) = \frac{SMA_{k^*-1}(t) - SMA_{k^*}(t)}{SMA_{k^*}(t) - SMA_{k^*+1}(t) + \epsilon}$$
$\rho^* < 0$ は、下位スケールが上位スケールを下抜け、順次傾きを反転させていく「反転カスケード」の起動を意味する。

#### 3. 動的超長期水平スケール $k_{\text{flat}}(t)$ とペンデュラム呼吸
超長期スケール群（610..4181）において傾きが水平化（$|slope_s| \le 0.0025$）した最大スケールを検出し、その呼吸レンジにおける極値からの反転をオシレーター乖離 $stoch\_gap = stoch\_z_{21} - stoch\_z_{k_{\text{macro}}} \ge 1.0$ で捉える。

## 4. 考察と結論

1. **K-074（スケールフリー動的極値看破ショート）の判定: 保留・条件付き知見 (Inconclusive / Constrained)**:
   - 固定値に頼らず、動的マクロスケールの支持床崩壊（$m_{\text{floor}} < -1.0$）、3スケール幾何反転カスケード（$\rho^* < 0$）、オシレーター乖離（$stoch\_gap < -0.30$）、AFS回帰（$afs\_L1 < 0$）を組み合わせることで、**2021年11月最高値 $69,000 天井圏からの暴落をピンポイントでショート（$64,544）** することに成功。
   - Mode A において**最大ドローダウンを `-12.7%` $\to$ `-9.9%`（+2.8%pt 改善）へ大幅低減**し、ドローダウン防衛において極めて有効な特性を示した。
   - ただし、Master Std においては確定マスター EXP-123（PF 5.45, Tot +535.8%）をわずかに下回る（PF 4.86, Tot +527.0%）ため、無制限マスターへの昇格は見送り、**「Mode A 厳格1ポジション排他運用および天井ドローダウン防衛フィルターとしての条件付き知見」** として位置づける。

2. **K-075（大底ペンデュラム反転と跳躍台ダブル波捕捉）の判定: 反証・観察知見 (Refuted as Standalone Signal / Observed as Contextual Pattern)**:
   - FTXショックのような歴史的大底における超長期水平呼吸（$k_{\text{flat}}$）からのペンデュラム反転は、場面3の第1波（+28.8%）の獲得において極めて強力な現象である。
   - しかし、全期間における機械的エントリーシグナルとして組み込むと、摩擦コスト（40 bps）と他の局面でのだましにより Mode A の利益を +337.3% $\to$ +316.4%、MaxDD を -12.7% $\to$ -22.3% へ悪化させる。
   - したがって、「独立したエントリーシグナル」としては明確に **反証（Refuted）** され、**「大相場転換点における文脈的観察知見（Observed as Contextual Pattern）」** として記録・資産化する。

3. **確定生産ベースラインの維持**:
   - 確定マスター生産ベースラインは、**EXP-123（Master Std: PF 5.45, Tot +535.8% / Mode A: PF 4.69, Tot +337.3%）を最高峰として維持** する。
